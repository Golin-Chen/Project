# Amazon Sales Data Power BI Dashboard Project

## 📌 Project Overview

This project uses **Microsoft Power BI** to build an **interactive sales dashboard** that provides analytics and insights from Amazon sales data. The purpose of this dashboard is to help users easily explore sales trends, key metrics, and performance patterns across products, time periods, regions, and customer segments using visuals and interactive controls.

By transforming raw sales data into compelling visual stories, this project demonstrates skills in data cleaning, business intelligence reporting, and dashboard design — all valuable for analytics and BI roles. 

---

## 🧠 What You’ll Learn

Through this project you will see competency in:

- **Data preparation & transformation**
  - Cleaning and structuring raw sales data to be analysis-ready.
  - Creating calculated columns and measures using **Power Query** and **DAX**.
- **Business Intelligence and Visualization**
  - Building interactive charts, KPIs, maps, and slicers that provide insights at a glance.
  - Designing dynamic visuals to support trend analysis and comparisons.
- **Analytical Interpretation**
  - Exploring sales performance over time and across categories.
  - Evaluating profitability, product performance, and customer behavior.

These skills are directly applicable to roles in **data analytics, business intelligence, and data visualization** — especially where Power BI is part of the tech stack. :contentReference[oaicite:1]{index=1}

## 🛠️ Tools & Technologies

This dashboard project was built using:

- **Microsoft Power BI Desktop** – for interactive report and dashboard creation
- **Power Query Editor** – for data cleaning and transformation
- **DAX (Data Analysis Expressions)** – for calculating dynamic measures and KPIs
- **Source Data Files** (e.g., sales CSV/Excel) – raw Amazon sales records :contentReference[oaicite:2]{index=2}

Together, these tools support an **end-to-end BI workflow** from raw data to visual insights.

## 📊 Key Features (Examples)

Examples of visuals and insights often included in this type of dashboard:

- **Sales Trend Analysis:** View how total sales and profit change over months or years.
- **Top Performing Products:** Identify which product categories or specific items drive the most revenue.
- **Regional Performance:** Map or chart that highlights sales distribution across locations.
- **Interactive Filters and Slicers:** Controls that let users drill down by time, category, or region.
- **Dynamic KPIs:** Cards showing metrics like Total Sales, Total Orders, and Profit Margin. :contentReference[oaicite:3]{index=3}

This makes the dashboard both informative and actionable for decision-making.
