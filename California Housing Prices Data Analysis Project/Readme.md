# California Housing Prices Data Analysis Project

## 📌 Project Overview

This project explores and analyzes the **California Housing Prices dataset**, a well-known regression dataset used frequently in data science and machine learning to understand how different housing and demographic features relate to housing value. The main objective is to **analyze the data, build predictive models, evaluate their performance, and draw meaningful insights** from structured real-world data.

The dataset includes features such as:
- Median income
- Median house age
- Total rooms & total bedrooms
- Population & household statistics
- Geographical information (latitude, longitude)

As part of this project, I demonstrated the following skills:

  - Feature distributions and summary statistics

- **Visualization**
