# Canadian Housing Affordability Index Data Analysis Project

## 📌 Project Overview

This project explores the **Canadian housing affordability index** — a quantitative measure that reflects how accessible housing is relative to household income and other socio-economic factors across Canada. By analyzing publicly available housing and demographic data, this project aims to uncover patterns in affordability and produce insights that can help inform stakeholders and decision-makers about housing cost pressures in different regions of Canada. :contentReference[oaicite:0]{index=0}

---

## 🧠 Key Objectives

In this analysis, I focused on:

- Calculating an **affordability index** using relevant housing and income data.
- Investigating how housing costs relate to income and demographic variables in Canada.
- Identifying **regional differences** in housing affordability across provinces or census areas.
- Communicating results through **clear visualizations** and summary statistics.

This helps illustrate both **data literacy** and an understanding of socio-economic context in applied analytics.

## 📊 What You’ll Learn

This project demonstrates:

- **Data acquisition** from real public sources.
- **Data cleaning and preprocessing** to handle missing values and normalize variables.
- **Calculating custom metrics** like affordability ratios or indices.
- **Exploratory Data Analysis (EDA)** using statistics and visualizations.
- **Regional comparison** and interpretation of socio-economic indicators.
- **Communication of analytical insights** for a broad audience including non-technical stakeholders.
