# Housing Affordability Forecasting & Economic Impact Modeling
## 📌 Project Overview
This project builds a regression forecasting model to analyze the macroeconomic drivers of housing affordability across Canada, using data sourced from the Bank of Canada and Statistics Canada. The goal is to demonstrate an end-to-end analytics workflow, from data collection and pipeline design through model building, validation, and executive-ready reporting on housing and socio-economic trends.

---

## 🧠 Learning Objectives
Throughout this project I:
- Built an **end-to-end ETL pipeline** using Google Cloud, Python, Databricks, and SQL to ingest, clean, and structure macroeconomic and housing data.
- Applied **data quality and governance practices**, including validation checks and documentation, to keep the pipeline auditable and explainable.
- Developed a **multiple regression forecasting model** (Adjusted R-squared of 97.25 percent) to quantify how macroeconomic indicators drive housing affordability.
- Performed **feature selection and statistical diagnostics** to identify the most meaningful predictors of price sensitivity and affordability trends.
- Translated model outputs into **executive-ready insights**, focusing on pricing sensitivity and housing market planning.
- Practiced communicating technical modeling results to **non-technical stakeholders** through clear visualizations and summaries.
