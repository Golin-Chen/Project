# Financial Loan Risk Classification Data Science Project

## 📌 Project Overview

This project explores the process of analyzing loan data and building machine learning models to **classify loan risk** — specifically identifying loans that are likely to default versus those that are likely to be repaid. Using a large lending dataset, the goal is to demonstrate a full data science workflow: cleaning and transforming raw data, selecting and training classification algorithms, evaluating model performance, and interpreting results.

This project reflects core competencies in **data preprocessing, classification modeling, model evaluation, and deployment-ready preparation** — all essential skills for data science and analytics roles.

---

## 🧠 Learning Objectives

Throughout this project I:

- Performed **data cleaning and preprocessing** to handle:
  - Missing values
  - Data imbalances
  - Encoding of categorical variables
  - Feature scaling
- Built and compared various **classification models** such as:
  - Logistic Regression
  - Decision Trees
  - Random Forest
  - Gradient Boosting methods (XGBoost / LightGBM)
- Applied **evaluation metrics** appropriate for classification:
  - Accuracy
  - Confusion Matrix
  - Precision, Recall, F1-Score
  - ROC-AUC
- Addressed **class imbalance** with techniques like sampling or algorithmic adjustments.
- Interpreted model results and identified **important predictive features**.
